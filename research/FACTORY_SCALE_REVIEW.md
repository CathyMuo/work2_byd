## 2. L3 的定义需要拆开

报告类别总和：60+29+18+14+13=134。

| 数字 | 正确口径 |
| --- | --- |
| 74/134 = **55.2%** | “答案实体已出现，仍答错/未答”的 L3 **候选**占全部退化状态比例 |
| 92/134 = **68.7%** | 剔除 29 个非实体答案与 13 个双侧未匹配之后的代理判定覆盖率 |
| 74/92 = **80.4%** | 在代理可判定子集中的候选比例，不能当作全部状态的语义 L3 比例 |
| 74/105 = **70.5%** | 仅剔除非实体答案的另一口径；应与对应 pilot 口径比较 |

相同口径的 pilot/scale 比例接近可作为稳定性线索，但二者包含重叠已观察题，
不是独立确认。“strict”只是代理分母的命名，不意味着语义证明更严格。

答案实体出现是存在性线索，不证明它满足题目的关系、时间、身份或比较约束。
阿森纳/Jonker/Wenger 例子必须核对任职时间和具体角色；人名匹配不能证明
当前问题已获得充分答案证据。13 个未匹配案例也不能自动归因于别名，更不能
因此从总体删除。29 个 yes/no/数值案例需要关系/数值推导证据核验。

14 个空答案与 60 个错误答案必须单列。前者可能涉及 budget_exhausted、
generation_limit、格式/终止失败或继续搜索而未收束，不能一律解释成“忽略证据”。
先审查**全部 134 状态的所有退化条件事件**，不只审查已被代理筛成 L3 的 74 个。
如果四个条件的退化计数完整对应，事件应为 75+81+14+5=175，可能共享 134 个
状态；以原始数据为准，不硬凑这两个数。

“S1 perturbed visible 133/134”与上述严格代理口径相差很大。必须追溯 S1 是否
沿用了早期大写词/宽泛实体代理、是否误读 candidate20、是否混入 clean 或其他
干预分支。未完成这一检查前，删除“所有退化都排除了证据不可达”的强结论。
clean 轨迹上可取回，不能证明扰动状态剩余预算内存在可执行检索路径。

## 3. 恢复性与 B3

52/134=38.8% 是报告的“某基线实际修复过”子集，且 union 包含受限 oracle。
它是已尝试动作下的恢复见证；应再区分非 oracle 见证。82/134=61.2% 只是
**现有测试动作尚未修复**，不是不可恢复，也不自动证明更强动作一定有效。
原文“RFR-over-witnessed=1”若只从 B0 已失败的退化集合构造，是条件选择上的
恒等式，不是新的行为或研究证据。

B3 修复 44 个退化，同时损害 53 个 stable 状态。若二者对应同一种 B0 分支
定义，在 134+449=583 个状态上净 **44−53=−9**，即 −1.54 个 EM 百分点。
1389 个 clean-wrong 状态的改善/损害没有给出，不能推断全量净收益为负或正。
这支持测试选择性触发的动机，尚不证明任何触发器能够识别这些状态。

必须核查：一个状态有多种退化条件时 B 使用哪支；是否根据 gold/EM 选择最坏
分支；B3 的“缺失子目标”是否用了金标；B1 是总预算 6 还是重新给 6 次；B3 的
额外 prompt/input/生成成本是否计入；B2 是否真正执行过而非 fallback/no-op。
每支应从同一 A3 扰动状态恢复，不能从头重跑问题替代恢复。

B5 的 3/14 只衡量该种 oracle 操作在 E3 子集的表现，不是所有可恢复动作的
理论上界。部署方法和 oracle 结果分开，不能把 oracle 信息当作触发特征。

## 5. 与已核实的邻近工作相比

[Lazy Grounding](https://arxiv.org/html/2608.30303v2) 已研究真实但支持邻近问题的
证据被误用，包括位置/答案形式影响及约束核对防御。故“真文档也能带偏、加一个
约束核对 prompt”本身不是新的定位。

[ACL 2026 Context Interference](https://aclanthology.org/2026.acl-long.160/)
已分析多轮搜索上下文干扰并采用 context refinement；不能仅以“去干扰后提高
分数”区别于它。

[R²-Searcher](https://arxiv.org/abs/2606.28566) 提出问题 token 指引的事实上下文和
检索后反思，故“抽证据/做反思/联合 RL”也不能单独作为创新点。

可检验的潜在方向是：**证据语义已充分时，哪些可观察状态特征预测答案选择或
终止失败；针对它们的动作为何修复，同时怎样控制稳定正确状态的损害。** 这只是
候选定位，须用因果对照和独立确认与上述方法比较，尚无原创性结论。报告中的
“ICML 2026 Open-World”缺完整题名/标识，本次不把它当已核实引用。
