旧方向是“检索漂移 → 恢复”，已归档 NO-GO。新方向把旧实验里反复出现的现象当作研究对象：

> 任何干预（删证据、反思提示、加预算……）的效应，都要先减去同状态“语义空”干预的效应，才能解释。

## 3. 状态 s 上的分支臂（都从同一原始 token 前缀分叉，预算从已花费的次数接着算）

| 臂 | 族 | 定义 |
| --- | --- | --- |
| `clean_a`, `clean_b` | E0 控制 | 原样观测。两条都必须逐 token 复现源轨迹的后续，否则整批停止 |
| `perm_1..4` | N1 安慰剂 | 同三篇文档，取 4 个不同的非恒等排列，由 `sha256(sample_id|turn|perm)` 决定，与结局无关 |
| `fmt_1`, `fmt_2` | N2 安慰剂 | 只改渲染格式（分隔符/标题行），标题与正文逐字节不变、顺序不变 |
| `review` | 恢复 | SI1 review 提示原文，接在 clean 观测后 |
| `neutral` | P2 安慰剂 | 语义空文本，token 数与 review 提示**完全相等** |
| `budget2` | P3 | 总预算 +2，不加任何文字（B1 的对应） |
| `perm1_review` / `perm1_neutral` / `perm1_budget2` | 选择型恢复 | 同样三种操作，接在 `perm_1` 扰动后的观测上（复现 B 的设计） |
| `drop_support` | 内容 | 把含支持事实代理（标题+句子词法命中）的那一篇，换成候选 rank 4–20 中第一篇“无事实命中、无答案串”的文档 |
| `drop_nonsupport` | 内容对照 | 用**同一篇**替换文档，换掉一篇无事实命中、无答案串的文档 |

所有臂对每个状态都跑（结局出来之前就分配好），分层都在事后用同一规则划分。删除臂的替换长度比限定在 [0.5, 2.0]；
不满足条件的记为 ineligible 并写明原因，不放宽规则。

## 4. 估计量

- 格式性翻转：EM 翻了，但两条答案在规范化后相等、互相包含，或 token F1 ≥ 0.8。主结果一律用
  **semantic 视图**（格式性翻转按“未翻转”计）；raw EM 视图并列报告。
- p(s) = 6 个安慰剂臂（N1×4 + N2×2）的平均正确率。
- Lucky success：clean 答对且 p(s) < 0.5；Unlucky failure：clean 答错且 p(s) ≥ 0.5。
- Lucky share = lucky success / clean 答对数；Luck rate = (lucky + unlucky) / 状态数。
- mEM = 平均 p(s)；rEM = 6 个安慰剂臂全对的比例。
- NCE(I) = E[Y_I − p(s)]，同状态配对。
- Exp-2 选择型：D = clean 对且 perm_1 错（对应 B 的退化层），S = clean 对且 perm_1 对（稳定层）。
  修复率 R(I) = D 上 `perm1_I` 答对的比例；安慰剂修复率 P1 = D 上 `perm_2` 答对的比例（换一个排列），
  P2 = D 上 `perm1_neutral` 答对的比例；误伤率 = S 上答错的比例，安慰剂误伤率同理。
  未校正净值 = R·|D| − H·|S|；校正净值 = (R − max(P1, P2))·|D| − (H − H_P2)·|S|。
- Exp-3：在两个删除臂都可用的状态上配对，算 NCE(drop_support)、NCE(drop_nonsupport) 和二者之差；
  另报“丢掉的事实此前从未出现过”的子层。
- 区间：按整题重抽（同一题的各轮一起抽），在数据集内分层，2000 次，seed 42。

## 5. Go / No-Go（只在 Exp-1/2/3 全部完成后判定一次）

- **G1**：semantic lucky share ≥ 10%，且 95% CI 下界 > 5%。
- **G2**：`review` 或 `budget2` 中至少一个满足：安慰剂修复率 / 修复率 ≥ 1/3，或校正前后净值方向相反。
- **G3**：drop_support − drop_nonsupport 的 95% CI 上界 < 0（PCR 能分辨真证据，不是“全是噪声”）。

处置：
- G1 不成立 → 路径运气不普遍，停止本方向，最多写成评测协议短文。
- G1 成立、G3 不成立 → “智能体几乎不用单轮证据”本身就是发现，论文转为纯分析型。
- G2 不成立 → 删去 RQ3（恢复收益是真的），保留 RQ1/2/4 和 LDR。
- 全部成立 → 进入 Phase 2（多检查点/数据集/检索器/温度）和 Phase 3（LDR 训练），各自另立协议。

`pcr_analysis` 只输出门槛的机械值。是否 GO 由人在 `DECISION_LOG.md` 里记录，不能自动推进到 RL。

## 6. 已知局限（写进论文局限一节）

- 支持事实是词法代理，不是语义认证；删除臂换掉的槽位，在 support 和 nonsupport 之间可能不同（报告里有 slot 字段，可以按槽位分层）。
- N2 格式变体本身可能对模型有系统性影响；所以单独报每个臂的翻转，如果 N2 和 N1 差异很大，就分别报告。
- 单一 7B PPO 检查点；Phase 2 才扩展。
- 温度 0：p(s) 的随机性只来自观测呈现，不含采样；温度 > 0 的方差分解留到 Phase 2。
